# 🎱 Simple Billiard Scoreboard

A clean, high-contrast, simple scoreboard web application designed for tablets mounted next to pool tables.

## Features
- ⚡ **Ultra-readable UI:** Large, clear numbers visible from across the room.
- 🏆 **Set & Score Tracking:** Keep track of points and set counts easily.
- ⏱️ **Integrated Match Timer:** Built-in timer with start/pause/reset controls.
- 📱 **Tablet Optimized:** Built for landscape view with big touch targets.
- 📶 **Offline-ready:** A single standalone HTML file with zero external dependencies.

## How to Use
Simply open `index.html` in any web browser on your tablet.

Designed to run on a tablet mounted next to the table.
